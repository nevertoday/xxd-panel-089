# XXD Panel 089 オリジナルプロンプト · 日本語読解訳

アップロードした写真を一枚ずつ、それぞれ独立した上質なデザインポスターにしてください。複数画像をつなぎ合わせず、写真ごとに個別に出力します。全体は3:4の縦構図とし、上下2つの領域の高さを厳密に1:1、各領域を画面の50%にします。

上半分には元の写真を残し、主体の同一性、構造、ポーズ、リアルな質感、自然な光と影、元来の色彩の雰囲気を保ってください。調整は控えめで上質なカラーグレーディングのみにとどめ、アート雑誌、インディペンデント出版物、展覧会写真のような質感にします。画面比率に合わせて周囲の背景を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別しやすい主体、輪郭、ポーズ、物語上の関係を抽出し、手帳らしい趣のある一組の Hand-drawn Lifestyle Spot Illustration として再構成します。場面全体を描き直してはいけません。写真の中で最も記憶に残る主体と細部を、複数の独立した小品イラストへ分解してください。比較的明確な一つの主体ユニットに物語の核を担わせ、さらに元画像から少数の動作、部分的特徴、植物、器物、食べ物、服飾、建築の細部、素材、または偶然写り込んだ物を抽出し、補助的な視覚断片にします。各要素は独立して存在させ、完全な背景や統一された遠近法を構築しません。

構図には浮遊する散点型の編集レイアウトを採用し、大きさ、高低、疎密、方向の自然な変化を強調して、それぞれの小さなイラストを紙面にさっと記録した生活の断片のように見せます。主体の視覚的な比重を最も高くし、ほかの要素はその周囲でゆるやかに響き合わせます。余白をたっぷり残し、一部の要素はわずかにはみ出したり、傾いたり、文字と交差したりしても構いませんが、均等に並べたり、規則的なグリッドにしたり、ステッカー商品のカタログのようにしたりしてはいけません。全体は一見無造作でありながら、実際には明確な視覚的重心、視線の流れ、余白のリズムを備えていることが必要です。

画風は、ゆるく素朴な手描き線 + 水彩 + 色鉛筆 + 少量のソフトパステルの質感とします。線は細く自然で、わずかな手ぶれやためらいを感じさせます。比率は完全に正確でなくてもよく、輪郭は少し歪んだり途切れたりして構いません。色は線からわずかにはみ出したり、塗り残しがあったりしてよく、紙の地、鉛筆の粒子、水彩の薄い層、部分的なクレヨンの擦れを残します。全体は親しみやすく、私的で、力の抜けた雰囲気にしますが、幼稚な漫画調にはしません。

配色は、上の写真から最も明るく鮮やかで、画面の生命感を最もよく表す色を選び、再び柔らかく純化します。色を均等に拾ってはいけません。元画像を自然に、澄んだ青、湖水のような青緑、若草色、クリームイエロー、アプリコットオレンジ、コーラルピンク、柔らかな紫などの軽やかな複合色へ置き換えます。明るいウォームホワイトの紙面を主な呼吸空間とし、爽やかな寒暖関係と少数の高明度アクセントによって癒やしを生み出します。色は鮮やかでありながら柔らかくし、暗く、古びた、モランディ調のくすんだ色にはせず、蛍光色や安っぽいキャンディカラーも避けます。

文字は、私的な手帳の中の hand-lettered annotation のように自由に介入させ、固定のタイトル、場所、番号、言語をあらかじめ設定しません。写真の動作、気分、音、匂い、記憶、偶然の細部に応じて、少数の単語、短い文、ふと漏れた感嘆、記号を生成できます。細く自由で、筆圧にわずかな変化があり、ベースラインが自然に揺れる手書き文字を用います。字形は少し不規則でも、軽やかさと読みやすさを保ちます。文字はイラストの間に挟んだり、物の輪郭に沿わせたり、斜めに散らしたり、余白の一角を占めたりでき、小さなイラストとともに自然な図文混植をつくります。リズムをつけるため、ごく少数の小さな星、短い線、点、手描き記号を加えても構いませんが、過度に装飾してはいけません。

全体は、丁寧に編集された私的な暮らしの手帳、インディペンデント雑誌の挿入ページ、アーティストのビジュアルダイアリーのようにします。軽やかで、ゆるく、断片的で、日常的で、優しく、癒やしがあり、わずかに素朴でありながら、成熟した余白、構図、編集デザインの意識を備えます。場面全体の描き直し、複雑な背景、規則的なグリッド、ステッカーUIのような印象、太い黒輪郭、子ども向け漫画、精密なベクター、3Dレンダリング、商用テンプレートのような印象は避けてください。
